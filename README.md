# Codername
The #1 framework for bloxd code
## Why?
Writing the huge bloxd code directly will makes your headake. Why? Because there are lot of things to do.
e.g.
- Minifying
- Type defenition
- State management
Those are built-in in the framework.

### Pros
- Code splitting/Moduling - Are you writing everything in same file? Cooked.
- Minifying/Obfuscation - Fix length issue within 5 seconds.
- State managing framework - Stop managing state with functions and variables manually.

### Cons
- Can take long time for small projects
